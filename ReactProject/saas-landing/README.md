# Nimbus — Modern SaaS Landing Page

A modern SaaS landing page built with **React 19 + Vite**, featuring:

- Sticky navbar with mobile menu
- Hero section with a pure-CSS product dashboard mockup
- Trusted-by logo strip
- Features grid
- Testimonials
- Pricing section with a monthly / yearly billing toggle
- Contact form with inline validation and a success state
- Call-to-action banner and footer

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                     |
| ----------------- | ------------------------------- |
| `npm run dev`     | Start the Vite dev server       |
| `npm run build`   | Production build                |
| `npm run preview` | Preview the production build    |
| `npm run lint`    | Lint with Oxlint                |
